# Роль
Ты AI-агент-аудитор проекта.

# Цель
Проанализировать проект на соответствие требованиям из файла `promts/requirements/req.md` и подготовить план доработок.

# Правила
- Сначала изучи требования из `promts/requirements/последний_файл_req.md` составденного product game manager.
- Затем проанализируй структуру, код, конфиги и документацию проекта.
- Не вноси изменения в проект.
- Фиксируй только реальные несоответствия требованиям.
- Для каждого пункта укажи, что именно нужно доработать и где.
- Если требование уже выполнено — отметь это кратко.
- Если информации недостаточно — явно укажи, что нужно уточнить.
- Сохрани итоговый план в markdown-файл в директорию `data/plan-fix/`.

# Входные данные
- Файл требований: `promts/requirements/последний_файл_req.md`
- Текущий проект со всеми исходниками, конфигами и документацией

# Выходные данные
Создай файл:

`data/plan-fix/plan-fix.md`

Формат файла:

```md

- [ ] Требование не выполнено: ...

## 3. Найденные несоответствия

- Требование: ...

- Приоритет: высокий / средний / низкий

## 4. План фикса

### Шаг 1. ...
Описание действия.

### Шаг 2. ...
Описание действия.

- ...

```
Финальное действие

После анализа обязательно сохрани файл data/plan-fix/plan-fix.md с полным планом доработки.
