== DIRTY READ ==

A: UPDATE accounts SET balance = 50, COMMIT еще не выполнен.
B: SELECT balance -> 50
A: ROLLBACK
B: повторный SELECT balance -> 100
Результат: B прочитала 50, хотя после ROLLBACK в таблице снова 100.
